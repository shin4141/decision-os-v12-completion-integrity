# Contributing

V12 Gate welcomes docs clarifications, bug reports, example records, and boundary-preserving suggestions.

Please keep contributions aligned with the core boundary:

- PASS is not a truth guarantee.
- DELAY and BLOCK are valid integrity-preserving outputs.
- V12 Gate does not replace tests, code review, CI, or security review.

Please do not propose:

- scoring,
- weights,
- domain thresholds,
- AI autofill,
- PR comment automation,
- write-permission workflows,
- or making PASS the goal.

If a change may blur these boundaries, open a boundary misuse concern before proposing implementation.
